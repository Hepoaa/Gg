# Android — pasos mínimos

1. Extrae `FamilyOS-Cloudflare-OneClick.zip`.
2. Sube TODO el contenido extraído a un repositorio GitHub.
3. Para despliegue de un clic, haz el repositorio público.
4. En Chrome abre:
   `https://deploy.workers.cloudflare.com/?url=https://github.com/USUARIO/REPOSITORIO`
5. Toca **Deploy to Cloudflare**.
6. Cuando Cloudflare lo solicite, pega `NVIDIA_API_KEY` y crea un `SESSION_SECRET` largo.
7. Confirma el despliegue.
8. Al terminar abre la URL `workers.dev`.
9. Completa el onboarding de FamilyOS.
10. Instala la PWA con el botón **Instalar FamilyOS**.

No necesitas buscar ni copiar ningún Database ID.
